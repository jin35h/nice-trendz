# NICE TRENDZ Static Website

Responsive multi-page HTML/CSS/JavaScript/jQuery website starter for NICE TRENDZ, Prantij, Sabarkantha.

## Included
- Home, About, Fabric Collections, Tailoring, Wedding Wear, Gallery, Contact, FAQs
- Fabric Care Guide, Measurement Guide, Wedding Checklist, Style Journal, Privacy Notice
- WhatsApp enquiry links and a contact form that prepares a WhatsApp message; no server-side submission
- Responsive layout, mobile menu, gallery lightbox, FAQ accordions, SEO metadata, LocalBusiness/ClothingStore/ Tailor JSON-LD, sitemap and robots file
- Uploaded logo and storefront image plus remote illustrative stock photos

## Before publishing
1. Replace every `https://www.example.com` with the real domain in canonical tags, Open Graph tags, JSON-LD and sitemap.
2. Confirm address spelling, opening days/hours, phone numbers and WhatsApp number.
3. The owner supplied 9:30 AM–7:00 PM but did not specify the weekly closing day. Confirm before publishing `Mo-Su 09:30-19:00` in schema.
4. Verify all stock images and replace with licensed/original business photos when available.
5. Do not publish specific fabric brand names until stock is verified. No brand names are represented as confirmed inventory.
6. Link the real Google review URL or use an approved review embed. This site does not fabricate reviews or ratings.
7. Confirm return, exchange, cancellation and tailoring policies before publishing detailed policy terms.
8. Review the privacy notice and any analytics/cookie disclosures before launch.
9. Test WhatsApp, phone, maps and social links on mobile.

## Run locally
Open `index.html` in a browser. A local static server (e.g. VS Code Live Server) is recommended.

## Deploy
Upload the contents of this folder to the public web root of your static hosting account. No backend or database is required.
